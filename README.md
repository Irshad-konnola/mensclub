## 💡 The Problem & Solution

Brick-and-mortar retail apparel brands often struggle to bridge online discovery with in-store foot traffic, relying solely on social media posts that lack search engine indexability for high-intent local queries (such as formal wear, wedding ethnic collections, and custom tailoring).

**Men's Club Store (`mensclubstore.in`)** solves this with a performance-first retail storefront:
- **Rich Local Business SEO (`Schema.org` JSON-LD):** Implements structured metadata (`ClothingStore` / `LocalBusiness` schemas), OpenGraph tags, and semantic routing so search engines surface store hours, location data, and product categories directly in local search results.
- **Lookbook-Grade Visual Performance:** Uses Next.js image optimization to serve crisp apparel photography across formal wear, casuals, and bespoke tailoring collections with zero layout shift (CLS).
- **Direct Customer Conversion:** Integrates instant WhatsApp catalog inquiry and store-direction triggers tailored for mobile shoppers.

## ✨ Key Features

- **🔍 `Schema.org` Structured Data Architecture:** Rich JSON-LD metadata engineered for maximum local search visibility and high click-through rates.
- **🧥 Interactive Apparel Lookbooks:** Categorized showcases for Formal Wear, Ethnic & Wedding Collections, Casuals, and Custom Tailoring services.
- **✨ Smooth Framer Motion Transitions:** Tactile hover states, staggered gallery animations, and mobile-first navigation drawers.
- **📱 Mobile-First Retail UX:** Optimized for fast loading on mobile networks with one-tap store locator and inquiry actions.

## 🚀 Getting Started (Local Development)

### 1. Clone the repository
```bash
git clone [https://github.com/Irshad-konnola/mensclub.git](https://github.com/Irshad-konnola/mensclub.git)
cd mensclub
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.
